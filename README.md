# Komentář k zákonu č. 44/1988 Sb., o ochraně a využití nerostného bohatství (horní zákon)

Otevřený komentář k hornímu zákonu — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; vyhrazené a nevyhrazené nerosty, výhradní ložisko, ložiskový průzkum a zásoby, chráněné ložiskové území, dobývací prostor, plány otvírky, přípravy a dobývání, úhrady z dobývacího prostoru a z vydobytých nerostů, důlní škody a jejich náhrada.

Konsolidované znění: dokument e-Sbírky `SB-1988-00044_2025-07-01`.
